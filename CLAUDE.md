# CLAUDE.md

Las reglas de este repositorio están en **[AGENTS.md](AGENTS.md)**. Léelo completo antes de cualquier tarea,
en especial las secciones 5 (Reglas de Oro), 6 (Convenciones Técnicas) y 7 (Instrucciones para Asistentes de IA).

Resumen mínimo:
- Todo en español. Alcance limitado al Issue asignado.
- Replica la estructura de `src/services/cajeros` (.NET) o `src/services/notificaciones` (Node.js).
- Sin datos reales ni secretos. Sin firmas de IA en commits ni PRs.
- Verifica con `dotnet build && dotnet test` o `npm run lint && npm test` antes de terminar.
